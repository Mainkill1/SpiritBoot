# Research results

Promote only reproducible, non-proprietary results here.

Each result set should identify exact source revisions and enough environment metadata to reproduce it. Keep large/raw captures outside Git when needed; commit a compact summary plus hashes/locations.

Suggested layout:

```text
YYYY-MM-DD-topic/
  README.md
  environment.json
  summary.json
  normalized-results.jsonl
```
