# Provenance boundary

This patch was authored from SpiritBoot's independently implemented
`nxstorage/native_packet.c`, its owned packet/adapter/request tests, the exact
release-i386 output built from that source, and the marker-bounded runtime
profile generated by the public request replay fixture.

No Microsoft ClassPnP or Disk implementation, private helper body, or legacy
nxcdrom implementation body was inspected or used.  No external implementation
source was surveyed because the problem was a measured code-generation residue
inside the owned implementation: promoted arithmetic, a variable byte-copy
loop, and generic alignment checks around native aligned objects.

Public/native interface layouts and command lengths are compatibility facts
already frozen by SpiritBoot's admitted packet contract and target assertions.
The behavior spec was written before the candidate source change.  This record
describes the technical separation and is not a legal certification.
