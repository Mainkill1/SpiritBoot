## T1: concrete first assignment

The production module accepts a caller-owned idle packet envelope containing an allocated child IRP, resident SRB/sense, the actual borrowed MDL and trusted descriptor extent evidence. It accepts a copied core command or bounded internal control command and validated lower stack/addressing/timeout configuration. It supplies two narrow operations:

1. **Prepare an idle packet.** Validate input before altering live resources. Require a descriptor for nonempty data independently of its numeric virtual base; check the single-descriptor contract, byte/PFN extent evidence, original-domain subrange, overflow, page limits and applicable alignment. 2. **Capture terminal results by value.** Snapshot token, terminal child IOSB status/Information, SRB base/modifiers and bounded sense before any caller can retire/reuse packet storage. Use actual IOSB bytes, reject over-counts, distinguish dispatch pending from terminal status, preserve native failure distinctions.
