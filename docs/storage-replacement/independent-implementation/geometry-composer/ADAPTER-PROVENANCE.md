## Independent design and necessary convergence

GEOMETRY-ADAPTER-SPECIFICATION.md was frozen before production behavior.
The source names, staged snapshot/query/composer boundary, policy validation,
and host fault/ownership scenarios are newly authored. Necessary convergence
is limited to the retained entrypoint's ordinary C PFDO_EXTENSION/PIRP form,
approved public APIs/calling conventions, actual field names and numeric
ABI facts, event-acquire/release semantics, basic IOCTL 24-byte response,
terminal IOSB/count contract, FATX MBR signature, and the parent's observed
returned-prefix policy. The old handler's name/type/body/calculation and
status-only helper implementation were neither inputs nor templates.

The adapter's stack-local geometry/IOSB are initialized before lower building.
A no-write claimed success therefore encounters invalid fresh geometry rather
than stale valid fields. It validates terminal status/count and copied sector
agreement before serializing any caller bytes. The composer initializes the
base/optional prefix, including unknown checksum 0 and unavailable padding.
There is no second response composer or changed frozen source/header.

The owner event encloses one copied scalar snapshot. No layout pointer
survives release as a borrowed pointer, and no event ownership spans a lower
build, dispatch, or wait. An owner cache replacement during a test query
frees its previous cache allocation, changes style/identity/capacity/sector,
and invalidates the owner; the already copied coherent snapshot still drives
the response. This tests the new boundary under an original deterministic
API model, not the retained kernel's real concurrency/lifetime behavior.

The API double actually allocates and disposes synchronous child storage at
inline or pending completion. Sanitizers can therefore detect child reads
after disposal. The adapter never completes/frees a parent or synchronous
child. The enclosing host dispatch assigns status and completes exactly once;
one scenario frees the upper allocation during that completion. These tests
exercise actual production functions and do not extract old code.
