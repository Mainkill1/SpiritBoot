# Public baseline query observations

These are raw public-API observations against the exact released64 BIOS, not measurements of the replacement. Native runs use Steam Deck and the operator-approved Windows Ryzen host. Output arrays retain sentinel bytes and exact returned statuses and caller IOSB. On errors, an unchanged caller IOSB is not proof of the internal driver Information value. Numeric fields remain in the original structured probe schema; matching both hosts is xemu evidence, not physical-Xbox qualification.

The full raw artifact references, binaries, hashes, method constraints and run identities are documented in ../NATIVE-BASELINE.md. No old storage implementation body or private helper was consulted by the independently authored public XBE probes. Geometry composer revisions use only admitted returned-count/initialized-record observations, with remaining union/style/native adapter parity clearly unqualified.
