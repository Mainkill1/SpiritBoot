# Baseline provenance and footprint audit

This is the investigator's read-only audit of the pinned legacy-reference BIOS.
It records exact source/artifact bindings, the 22 SDK/DDK helpers, five additional
SCSI utility identities and compiled occurrences, retained license obligations,
GCC pipeline facts and ROM/kernel accounting. It does not certify the candidate.

`manifest.json` pins the archived reports and the separate large raw source
ledger. Preserve this evidence when replacing the class layer; do not provide
excluded source or private implementation bodies to fresh authors. Existing
compatible GPL, MIT, BSD, public-domain and runtime-exception notices remain
separate obligations and must be retained where applicable.

Static whole-kernel RAM and compressed payload size are measured here. Native
storage allocation high-water remains unknown. The final candidate needs actual
link/source closure and native memory measurements before the license and
footprint gates can pass.

The [helper-grant follow-up](helper-grants-followup/FOLLOWUP.md) binds all 27
remaining identities to their import history and records four generated-helper
source mappings. No compatible original grant for the 27 was established; their
compiled bodies must disappear or receive separately verified permission. The
metadata repositories’ MIT notices do not relicense original SDK/WDK headers.
This evidence is for provenance reviewers and remains outside the approved
independent-author input packet.
