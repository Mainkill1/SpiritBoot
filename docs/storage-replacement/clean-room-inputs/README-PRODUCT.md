This directory archives the exact behavior specifications, declaration-only exports, numeric ABI facts and permitted-input manifest given to the independent authors. The original 24 scoped source exports remain in the separate implementation package, rather than being duplicated here. The subsequently approved target-api-declarations.h and compiler-measured numeric fact headers are included here; they contain no helper implementation. SHA256SUMS is the original full package ledger: source-prefixed entries refer to that separate package and cannot be checked solely from this documentation directory. This is not a new grant for an excluded source or a claim of final license qualification. Current assembled source can reconstruct unmodified source exports using origin_path and exact source_sha256; the declaration-only SCSI export and filtered partition-owner header must use their separately recorded filtered bytes, never the full original header, excluded private typedef or unknown helper bodies. ABI-PROBE-RECEIPT.json records target/compiler/dependency identity and the limits of the constant-only probes.
