# Test Layout

Run the implemented host suite with:

```sh
python3 -m unittest discover -s tests/host -v
```

The current emulator baseline builds Roswell's open API-regression XBE from the
pinned reference checkout. [BUILD_AND_RUN.md](../docs/BUILD_AND_RUN.md) gives the
commands; [baseline evidence](../docs/provenance/OPEN_FIRMWARE_BASELINE.md) records
the separate release/checked results and known TODOs. The Open firmware workflow
also runs this integration path. No retail game data is part of the test fixtures.

Planned test groups:

## host

Tests that run without an Xbox or emulator. First candidates:
- XBE parser validation;
- export table generation/lookups;
- image/layout tooling;
- FATX parsing once added;
- trace/event serialization.

## xbe

Small open XBEs used to probe one behavior at a time. Prefer nxdk-built payloads with explicit expected results.

Examples:
- entry/stack validation;
- memory allocation/protection;
- thread creation and synchronization;
- timer behavior;
- file/device I/O;
- exception behavior;
- input/video/storage probes.

The release-only [Forza map-stream fixture](xbe/forza-map-stream/README.md)
replays the retained public request shape from the late world-streaming failure:
1,024 asynchronous FATX reads at queue depth 12 under a 900-page pressure
target, repeated for 16 measured passes. It uses generated bytes and contains
no title data. `tools/forza_map_stream.py` qualifies and compares its serial
captures.

`tests/host/test_fatx_read_extent_candidate.py` locks the final ordered FATX
extent patch, its one-entry generation-checked shape, exact-production helper
tests, async coupling tests, and independent design contract. The assembled
source additionally runs `tests/host/fatx/check-read-extent-cache.py` in plain
and sanitizer builds; this is the executable oracle rather than the lock test.

`tests/host/test_nxstorage_production.py` runs the final packet preparation
oracle in plain, ASan/UBSan and, when Clang is available, MSan modes.
`test_ata_cache_capture_candidate.py` and `test_ata_stall_candidate.py` lock the
ordinary-I/O cache bypass and the four Alternate Status read protocol. Their
release-disassembly and native-run evidence is under
`docs/performance/evidence/forza-map-hotpath-20261015/`.

The Steam Deck marker-bounded release census and the disposition for every
function executed by the first 1,024-request pass are under
`docs/performance/evidence/forza-map-hotpath-20261015/deck-function-census/`.
Profiler CPU/wall time is diagnostic only; release fixture timing is collected
without the plugin.

## integration

Full SpiritBoot runs in xemu and later physical hardware.

Integration tests should assert trace milestones rather than relying only on screenshots or timeouts.
